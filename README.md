Cистема автоматизации администрирования телекоммуникационного оборудования.

Утилиты предназначены:
- для автоматизации работы с оборудованием Cisco (проверялось на IOS 12, 15, XE).
- для автоматизации работы с оборудованием Cisco ASA.
- для автоматизации работы с оборудованием Cisco NEXUS.

ВНИМАНИЕ !
Все утилиты поставляются как есть (AS IS). Используйте их на свой страх и риск.
Никакой ответственности за использование утилит автор не несёт.

## Установка
Склонировать репозиторий:
```bash
git clone https://github.com/Mammoth70/shiva.git
cd shiva
```
Установить пакеты:
```bash
pip install -r requirements.txt
```

## Состав

### show-ssh-txtfsm.py
Запуск для каждого устройства из перечня включаемых и исключаемых IP-адресов и групп (или из файла) одной из команд "sh ver", "sh inv", "sh ip int des" и т.п.
Обработка результатов по шаблону "textfsm" и составление словарей значений.  
Допускаются к выполнению только те команды, для которых есть шаблоны "textfsm".

### conf-jinja-txt.py
Генерация для каждого устройства из перечня включаемых и исключаемых IP-адресов и групп (или из файла) уникальной команды конфигурации.  
Используются БД конфигурационных параметров и шаблон jinja2.  
Предварительный просмотр полученных команд конфигурации.

### conf-jinja-ssh.py
Генерация для каждого устройства из перечня включаемых и исключаемых IP-адресов и групп (или из файла) уникальной команды конфигурации.  
Используются БД конфигурационных параметров и шаблон jinja2.  
Выполнение на всех устройствах сгенерированных команд конфигурации.

### conf-text-ssh.py
Выполнение для каждого устройства из перечня включаемых и исключаемых IP-адресов и групп (или из файла) конфигурационной команды cisco из текстового файла.

### sys-text-ssh.py
Выполнение для каждого устройства из перечня включаемых и исключаемых IP-адресов и групп (или из файла) конфигурационной команды huawei из текстового файла.

### show-ssh.py
Выполнение для каждого устройства из перечня включаемых и исключаемых IP-адресов и групп (или из файла) любой однострочной команды типа "wr", "sh ver", "sh inv" и т.п.  
Может использоваться для группового сохранения рабочих конфигураций на внутреннюю память устройств.

### save-conf.py
Выполнение для каждого устройства из перечня включаемых и исключаемых IP-адресов и групп (или из файла) команды "sh run".  
Запись полученных конфигураций в файлы вида "HOSTNAME-confg"

### save-conf-huawei.py
Выполнение для каждого устройства из перечня включаемых и исключаемых IP-адресов и групп (или из файла) команды "disp curr".  
Запись полученных конфигураций в файлы вида "HOSTNAME-confg".

### show-ssh-routercard.py
Выполнение на одном устройстве-маршрутизаторе команды "sh ip int bri".  
Обработка результатов и получение карточки маршрутизатора в тектовом виде.  
(Перечень IP-интерфейсов, с адресами, масками и VRF)

### util/util-acl.py
Анализ файла с ACL в формате Huawei.  
Преобразование ACL в формат Cisco и запись его в файл

### util/util-conf-check.py
Анализ структуры конфигурационного файла.  
Проверка объявления используемых объектов.  
Проверка использования объявленных объектов.
